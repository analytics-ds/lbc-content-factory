- **Voir le deck** : ouvrir `index.html` (ou la version en ligne GitHub Pages)
- Navigation : flèches du clavier, touche S pour le sommaire, clic sur les captures pour zoomer
- Impression / export PDF : Cmd+P depuis le navigateur (format 1280x720 par slide)

`base-artifact.html` et `app.html` sont des annexes de travail internes (simulation du cockpit, blueprint n8n), pas des livrables client.
